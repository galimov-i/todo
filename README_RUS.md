# Kanban-доска с отслеживанием времени

Минималистичное Kanban-приложение в стиле Trello с автоматическим отслеживанием времени. Разработано на Python, Flask, SQLite и чистом JavaScript.

## Обзор

Это приложение предоставляет простой, но мощный способ управления задачами по методологии Kanban с автоматическим отслеживанием времени, затраченного на каждую задачу. При перемещении задачи в колонку "В работе" таймер запускается автоматически. При перемещении в любую другую колонку таймер останавливается и сохраняет прошедшее время.

## Возможности

- **Четыре колонки**: К выполнению, В работе, Ожидание, Готово
- **Drag-and-Drop**: Перемещение задач между колонками перетаскиванием
- **Автоматическое отслеживание времени**: Таймер запускается при перемещении в "В работе"
- **Автоматическая пауза**: Таймер останавливается при перемещении в другие колонки
- **Постоянное хранение**: Все данные сохраняются в базе SQLite
- **Отображение в реальном времени**: Живое обновление таймера на активных задачах
- **История времени**: Просмотр детальных записей времени по каждой задаче
- **Адаптивный дизайн**: Работает на компьютерах и мобильных устройствах
- **Без внешних зависимостей**: Чистый JavaScript, без фреймворков

## Справочник API

### Задачи

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/tasks` | Получить все задачи, сгруппированные по статусу |
| GET | `/api/tasks/{id}` | Получить задачу с записями времени |
| POST | `/api/tasks` | Создать новую задачу |
| PUT | `/api/tasks/{id}` | Обновить заголовок/описание задачи |
| PUT | `/api/tasks/{id}/status` | Переместить задачу в другую колонку |
| DELETE | `/api/tasks/{id}` | Удалить задачу |
| PUT | `/api/tasks/reorder` | Изменить порядок задач в колонке |

### Таймер

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| POST | `/api/timer/{task_id}/start` | Запустить таймер вручную |
| POST | `/api/timer/{task_id}/stop` | Остановить таймер вручную |
| GET | `/api/timer/{task_id}/status` | Получить статус таймера |
| GET | `/api/timer/{task_id}/entries` | Получить записи времени задачи |
| GET | `/api/timer/active` | Получить все активные таймеры |

### Примеры запросов

**Создание задачи:**
```bash
curl -X POST http://localhost:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Новая задача", "description": "Описание задачи"}'
```

**Перемещение задачи в "В работе" (запускает таймер):**
```bash
curl -X PUT http://localhost:5000/api/tasks/1/status \
  -H "Content-Type: application/json" \
  -d '{"status": "in_progress"}'
```

## Руководство пользователя

### Создание задач

1. Нажмите кнопку **"+ Add Task"** в заголовке
2. Введите заголовок (обязательно) и описание (опционально)
3. Нажмите **"Save Task"**
4. Задача появится в колонке "To Do"

### Перемещение задач

1. **Перетаскивание**: Зажмите карточку задачи и перетащите в нужную колонку
2. Таймер автоматически запускается при перемещении в "In Progress"
3. Таймер автоматически останавливается при перемещении в другие колонки

### Просмотр деталей задачи

1. Нажмите на **иконку глаза** на карточке задачи
2. Просмотрите описание, общее время и историю записей
3. Используйте кнопки **Edit** или **Delete** по необходимости

### Редактирование задач

- **Быстрое редактирование**: Двойной клик на карточке задачи
- **Из деталей**: Откройте детали задачи и нажмите "Edit"

### Отслеживание времени

- **Автоматическое**: Таймер запускается/останавливается при смене колонки
- **Просмотр времени**: Отображается на каждой карточке в формате ЧЧ:ММ:СС
- **Индикатор активности**: Зелёная пульсирующая точка показывает работающий таймер
- **История**: Просмотр всех записей времени в деталях задачи

## Схема базы данных

### Таблица задач (tasks)
```sql
CREATE TABLE tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    description TEXT,
    status TEXT NOT NULL DEFAULT 'todo',
    position INTEGER NOT NULL DEFAULT 0,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);
```

### Таблица записей времени (time_entries)
```sql
CREATE TABLE time_entries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER NOT NULL,
    start_time INTEGER NOT NULL,
    end_time INTEGER,
    duration INTEGER,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (task_id) REFERENCES tasks(id) ON DELETE CASCADE
);
```

## Устранение неполадок

### Проблемы с базой данных

**Проблема:** Ошибка "Database not found"
```bash
# Переинициализируйте базу данных
python -c "from database.db import init_db; init_db()"
```

**Проблема:** Повреждённая база данных
```bash
# Удалите и создайте заново
rm kanban.db
python -c "from database.db import init_db; init_db()"
```

### Проблемы с таймером

**Проблема:** Таймер не обновляется в реальном времени
- Убедитесь, что JavaScript включен в браузере
- Проверьте консоль браузера на наличие ошибок
- Обновите страницу

**Проблема:** Время не сохраняется
- Таймер сохраняется при перемещении задачи из "In Progress" в другую колонку
- Убедитесь, что API-запрос выполнился успешно

### Проблемы с подключением

**Проблема:** Не удаётся открыть http://localhost:5000
- Убедитесь, что Flask-сервер запущен
- Проверьте, свободен ли порт 5000
- Попробуйте: `python app.py` и следите за ошибками
